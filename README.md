# Homestead Cleaning Co.

A responsive static website for Homestead Cleaning Co., serving Alabama.

The site uses `sweethome@hotmail.com` for quote requests. A phone number has
not been published because one was not provided.

## Run locally

Open `index.html` in a browser or run a local static server from this folder:

```powershell
python -m http.server 8000
```

Then visit [http://localhost:8000](http://localhost:8000).

## Deploy

Import this repository into Vercel as a static site. No build command or output
directory is required. Vercel will serve `index.html` from the project root.
